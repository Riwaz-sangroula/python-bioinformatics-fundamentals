# Python Bioinformatics Fundamentals

This repository documents my development of Python programming skills for bioinformatics and biological sequence analysis.

The goal is to build a strong foundation in Python while applying programming concepts to biological data.

## Current Topics

- DNA sequence manipulation
- Nucleotide counting
- GC-content calculation
- DNA complements
- Reverse complements
- Python functions
- Dictionaries
- FASTA file processing

## Scripts

### 01 — DNA Basics

Introduces basic DNA sequence operations including sequence length, nucleotide counting, and GC-content calculation.

### 02 — Reverse Complement

Builds DNA complements and reverse complements using loops and conditional statements.

### 03 — Sequence Functions

Introduces reusable Python functions and dictionaries for biological sequence analysis.

### 04 — FASTA Reader

Reads DNA sequence data from a FASTA file and extracts the nucleotide sequence for further analysis.

## Example Workflow

```text
DNA / FASTA sequence
```
